Distance-based phylogenetic inference with MEGA

Author

Jeet Sukumaran

MEGA estimates evolutionary distances from aligned sequences and uses those distances to infer phylogenetic trees. This tutorial constructs a neighbor-joining tree for eight living bear species, examines its branch lengths, estimates bootstrap support, and compares the result with other distance-based methods.

The complete workflow uses MEGA’s graphical interface. It begins with one provided FASTA alignment and creates every other file named below.

1 Preparation

1.1 Installing MEGA

Download the current graphical version of MEGA for the operating system from the MEGA website. Follow the installer provided for that platform.

Start MEGA and select Help | About MEGA. Record the installed version. The menu paths below follow MEGA 12.

1.2 Acquiring the example alignment

Download the course alignment:

Download bears-CYTB-aligned.fasta

Create the following project directories with the file manager:

/home/student/projects/learning/scientific-julia/bear-cytb-mega/
├── data/
│   └── bears-CYTB-aligned.fasta
└── results/

Save the downloaded file as:

/home/student/projects/learning/scientific-julia/bear-cytb-mega/data/bears-CYTB-aligned.fasta

This file contains one complete mitochondrial CYTB coding sequence from each of eight living bear species. It contains eight aligned sequences, 1,140 columns, and no alignment gaps. Each sequence label contains the species, accession version, and gene:

Ailuropoda_melanoleuca|NC_009492.1|CYTB
Helarctos_malayanus|NC_009968.1|CYTB
Melursus_ursinus|NC_009970.1|CYTB
Tremarctos_ornatus|NC_009969.1|CYTB
Ursus_americanus|NC_003426.1|CYTB
Ursus_arctos|NC_003427.1|CYTB
Ursus_maritimus|NC_003428.1|CYTB
Ursus_thibetanus|NC_009971.1|CYTB

Every analysis in this tutorial begins with this alignment. The tutorial next converts it to bears-CYTB-aligned.meg, then uses that converted file for tree inference.

2 Basic workflow

2.1 Converting the FASTA alignment to MEGA format

MEGA’s native text format records the aligned characters and the data type needed by its analysis tools.

  1. In the main MEGA window, select File | Convert File Format to MEGA.
  2. Select data/bears-CYTB-aligned.fasta from the project directory.
  3. If MEGA asks for the source format, select FASTA.
  4. In the Input Data Format dialog, select DNA.
  5. Retain ? for missing data and - for alignment gaps.
  6. Complete the conversion.

MEGA opens the converted text in its editor. The beginning of the file should contain a #MEGA declaration followed by a title and the first labeled sequence.

Select File | Save As in the editor and save the converted file as:

/home/student/projects/learning/scientific-julia/bear-cytb-mega/data/bears-CYTB-aligned.meg

The project now contains two data files:

File Role
bears-CYTB-aligned.fasta Provided, portable multiple-sequence alignment.
bears-CYTB-aligned.meg MEGA-formatted copy created in the preceding steps.

Close the text editor after saving the .meg file.

2.2 Opening and checking the alignment

  1. In the main MEGA window, select Data | Open A File/Session.
  2. Select data/bears-CYTB-aligned.meg.
  3. Select Data | Explore Active Data.

The Sequence Data Explorer should report eight sequences and 1,140 sites. Confirm that all eight labels listed above are present. Scroll across the alignment and confirm that the displayed data are nucleotides and that no sequence contains a gap.

Close the Sequence Data Explorer without closing the active data file.

2.3 Constructing a neighbor-joining tree

Select Phylogeny | Construct/Test Neighbor-Joining Tree.

Set the following analysis options:

Option Setting
Test of Phylogeny None
Substitutions Type Nucleotide
Model/Method p-distance
Substitutions to Include Transitions and transversions
Gaps/Missing Data Treatment Complete deletion

Retain all 1,140 alignment sites. Select Compute.

MEGA first calculates the proportion of different nucleotides for every pair of sequences. Neighbor joining then constructs one tree from that distance matrix. The Tree Explorer displays the result.

The tree is unrooted. Its rectangular display has a leftmost position, but that position does not identify an ancestor or biological root.

2.4 Inspecting the inferred tree

In Tree Explorer:

  1. Select View | Options.
  2. Open the Branch settings.
  3. Enable the display of branch lengths.
  4. Apply the change.

For this analysis, a branch length is an estimated p-distance: substitutions per aligned site along that branch. Longer branches represent greater estimated sequence divergence under the selected distance definition.

Open the Tree Explorer information box and confirm:

  • eight taxa were analyzed;
  • the tree is neighbor joining;
  • the distance is p-distance;
  • gaps and missing data used complete deletion; and
  • 1,140 sites were retained.

The giant panda, Ailuropoda_melanoleuca, has the most divergent sequence in this set and appears on a long branch. The brown bear and polar bear, Ursus_arctos and Ursus_maritimus, should appear as close relatives. These observations provide simple checks that the expected records were analyzed; they do not validate every inferred relationship.

2.5 Saving the tree and analysis record

Select the original tree tab in Tree Explorer, then save the following files:

  1. Select File | Export Current Tree (Newick) and save:

    results/bears-CYTB-nj-pdistance.nwk

  2. Select File | Export Analysis Summary and save:

    results/bears-CYTB-nj-pdistance-summary.txt

  3. Select File | Save Current Session and use the name:

    results/bears-CYTB-nj-pdistance

    Allow MEGA to add its native tree-session extension.

The Newick file stores the tree for use in other software. The analysis summary records the distance model, site treatment, and other settings. The native session reopens the interactive Tree Explorer state.

3 Follow-up workflows

3.1 Estimating bootstrap support

Close Tree Explorer while leaving the bear alignment active. Select Phylogeny | Construct/Test Neighbor-Joining Tree again.

Use the same p-distance and complete-deletion settings, but change:

Option Setting
Test of Phylogeny Bootstrap method
No. of Bootstrap Replications 1000

Select Compute.

MEGA resamples the 1,140 alignment columns with replacement, reconstructs a neighbor-joining tree from each resampled matrix, and reports how often each split in the original tree recurs. A value of 90 means that the split occurred in 90% of the bootstrap replicate trees.

Tree Explorer provides separate views of the original tree and the bootstrap consensus. Use the original-tree view for the inferred branch lengths. Use the support labels to describe repeatability under site resampling.

Export the original tree with its displayed support labels as:

results/bears-CYTB-nj-pdistance-bootstrap.nwk

Export the analysis summary as:

results/bears-CYTB-nj-pdistance-bootstrap-summary.txt

If the bootstrap consensus is also required, select its tab and export it separately as:

results/bears-CYTB-nj-pdistance-bootstrap-consensus.nwk

Bootstrap percentages are not posterior probabilities and do not state the probability that a clade is true. They are conditional on this alignment, distance definition, missing-data rule, and tree-building method.

3.2 Applying a multiple-substitution correction

P-distance counts observed differences. It does not account for sites that changed more than once during evolution. Repeat the neighbor-joining analysis with a corrected nucleotide distance:

Option Setting
Test of Phylogeny Bootstrap method
No. of Bootstrap Replications 1000
Substitutions Type Nucleotide
Model/Method Tamura-Nei model
Substitutions to Include Transitions and transversions
Rates among Sites Uniform rates
Gaps/Missing Data Treatment Complete deletion

Select Compute, inspect the original tree and support values, then export:

results/bears-CYTB-nj-tamura-nei-bootstrap.nwk
results/bears-CYTB-nj-tamura-nei-bootstrap-summary.txt

Compare this topology and its branch lengths with the p-distance result. The Tamura-Nei model allows unequal nucleotide frequencies and different rates for the two transition classes while correcting for unobserved multiple changes. It changes the definition of every entry in the distance matrix; it does not change the neighbor-joining algorithm.

3.3 Inspecting the distance matrix

With bears-CYTB-aligned.meg active, select Distance | Compute Pairwise Distances. Choose the same model and complete-deletion settings as the tree whose distances are being examined.

The result is an eight-by-eight symmetric matrix. Each off-diagonal entry is the estimated evolutionary distance between two bear sequences. The smallest values should correspond to the closest sequence pairs in the neighbor-joining tree. The matrix is the direct input to distance-based tree construction.

In the Distance Data Explorer, select File | Export/Print Distances or use the CSV export button. Select CSV output, choose Print/Save Matrix, then select File | Save As in the text editor and save:

results/bears-CYTB-tamura-nei-distances.csv

3.4 Comparing neighbor joining and minimum evolution

Select Phylogeny | Construct/Test Minimum Evolution Tree. Use the same Tamura-Nei, uniform-rate, complete-deletion, and 1,000-replicate bootstrap settings used above.

MEGA begins with a neighbor-joining tree and uses close-neighbor interchange to search for a topology with a smaller sum of branch lengths. Record the ME search level shown in the Analysis Preferences window.

Export:

results/bears-CYTB-me-tamura-nei-bootstrap.nwk
results/bears-CYTB-me-tamura-nei-bootstrap-summary.txt

Differences between this result and the NJ result arise from the tree-building criterion and ME search, because the alignment and distance definition remain the same.

3.5 Constructing a UPGMA tree

Select Phylogeny | Construct/Test UPGMA Tree and retain the same Tamura-Nei and complete-deletion settings.

UPGMA assumes a constant rate of evolution among lineages. That assumption makes every tip equidistant from the root and produces a rooted ultrametric tree. The rooted result is meaningful only when rate constancy is defensible; the presence of a root in the display is not evidence that the assumption is true.

Export the exploratory result and summary as:

results/bears-CYTB-upgma-tamura-nei.nwk
results/bears-CYTB-upgma-tamura-nei-summary.txt

4 Analysis choices

Workflow detail: Evolutionary-distance models
The distance model defines what a branch length measures.

Model Main assumptions and effect
p-distance Observed proportion of different sites; no correction for multiple substitutions.
Jukes-Cantor Corrects for multiple substitutions while assuming equal nucleotide frequencies and equal substitution rates.
Kimura 2-parameter Distinguishes transitions from transversions while assuming equal equilibrium nucleotide frequencies.
Tamura-Nei Allows unequal nucleotide frequencies and distinct transition rates and corrects for multiple substitutions.

A model with more parameters is not automatically more appropriate. Sequence composition, divergence, saturation, and the amount of information in the alignment determine which assumptions are defensible.

Workflow detail: Gaps and missing data
The selected rule determines which aligned sites contribute to each distance.

Treatment Effect
Complete deletion Removes every site containing a gap or missing state in any taxon, so all pairwise distances use the same retained columns.
Pairwise deletion Removes incomplete sites separately for each pair, so different matrix entries may use different columns.
Partial deletion Retains sites that meet a specified coverage threshold.

The course alignment contains no gaps or ambiguous bases, so all three rules retain the same 1,140 sites here. They need not agree for another alignment.

5 Recording the analysis

Preserve:

  • bears-CYTB-aligned.fasta;
  • bears-CYTB-aligned.meg;
  • each exported Newick tree;
  • each analysis summary;
  • the native Tree Explorer sessions needed for later interactive inspection; and
  • the MEGA version and operating system.

Report the tree-building method, evolutionary-distance model, rate treatment, gap and missing-data treatment, number of retained sites, bootstrap replicate count, and any rooting performed after inference.

Neighbor-joining and minimum-evolution results are unrooted. Rooting either tree is a separate biological analysis decision, even when MEGA draws the tree with a leftmost base.
