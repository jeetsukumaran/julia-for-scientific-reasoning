Phylogenetic inference tools – MrBayes

Author

Jeet Sukumaran

MrBayes estimates posterior distributions of phylogenetic trees and model parameters with Markov chain Monte Carlo (MCMC). A typical analysis reads an aligned NEXUS data set, defines an evolutionary model and its priors, runs independent Metropolis-coupled MCMC analyses, checks convergence and mixing, and summarizes the retained posterior samples.

The commands below use MrBayes 3.2.8. Most also apply to earlier MrBayes 3.2 releases.

1 Installation and help

Download the current source or a platform build from the MrBayes download page. On systems with Homebrew, install the available formula with:

brew tap brewsci/bio
brew install mrbayes

The Bioconda package can be installed with:

conda install bioconda::mrbayes

Package-manager releases can lag the current official release. Confirm the installed version and display command-line options:

mb -v
mb -h

Start an interactive session without a filename:

mb

MrBayes provides detailed help within the session:

MrBayes > help
MrBayes > help lset
MrBayes > help prset
MrBayes > help mcmc
MrBayes > help sump
MrBayes > help sumt

The manual command writes the complete built-in command reference to a text file. The reference reflects the options and defaults of the running executable.

2 Input data and command files

MrBayes reads aligned data in NEXUS format. Supported character types include DNA, RNA, protein, restriction-site, standard discrete morphological, and mixed data. A minimal DNA file has this structure:

#NEXUS

begin data;
    dimensions ntax=4 nchar=12;
    format datatype=dna missing=? gap=-;
    matrix
        Taxon_A  ACGTACGTACGT
        Taxon_B  ACGTACGTACGA
        Taxon_C  ACGTACGTTCGA
        Taxon_D  ACGTTCGTTCGA
    ;
end;

Before analysis, confirm that:

  • the matrix is an alignment of homologous characters;
  • ntax and nchar match the matrix;
  • every taxon has a unique label;
  • taxon labels avoid spaces and NEXUS or Newick punctuation;
  • datatype, missing, and gap describe the matrix correctly;
  • partition coordinates are one-based and match the alignment; and
  • the ascertainment-bias setting matches whether constant or singleton characters were retained.

Keep the data and analysis commands in separate files. This permits several analyses to use the same alignment without modifying it. Every command inside a begin mrbayes; ... end; block ends with a semicolon. Text in square brackets is a NEXUS comment.

Run a command file non-interactively and preserve the screen output:

mb analysis.nex > alignment_gtrig.screen.log 2>&1

Use a unique output name for every analysis. MrBayes does not silently overwrite existing output files under its default warning behavior.

3 A standard nucleotide analysis

Create analysis.nex with the following commands:

#NEXUS

begin mrbayes;
    set autoclose=yes nowarnings=no quitonerror=yes;
    set seed=20260922 swapseed=4260901;
    execute alignment.nex;

    lset nst=6 rates=invgamma ngammacat=4;
    prset statefreqpr=dirichlet(1,1,1,1);
    showmodel;

    mcmcp nruns=2 nchains=4 temp=0.1 ngen=2000000
        samplefreq=1000 printfreq=1000
        mcmcdiagn=yes diagnfreq=5000
        diagnstat=avgstddev minpartfreq=0.10
        relburnin=yes burninfrac=0.25
        stoprule=no checkpoint=yes checkfreq=10000
        filename=alignment_gtrig;
    mcmc;

    sump relburnin=yes burninfrac=0.25;
    sumt relburnin=yes burninfrac=0.25;
end;

The commands and parameters have the following meanings:

Command or parameter Meaning
set autoclose=yes Ends the requested MCMC run without asking whether to add generations. This is appropriate for batch execution.
nowarnings=no Retains prompts that protect existing output files. Use a fresh filename so a batch job does not stop at an overwrite prompt.
quitonerror=yes Terminates batch execution after an error instead of waiting for more interactive input.
seed Sets the main pseudorandom-number seed. Set it before execute so default starting values derived while reading the matrix are reproducible.
swapseed Sets the pseudorandom-number seed for swaps among cold and heated chains.
execute alignment.nex Reads the alignment and any definitions in alignment.nex.
lset nst=6 Uses the general time-reversible (GTR) nucleotide substitution model.
rates=invgamma Estimates both a proportion of invariable sites and gamma-distributed rate variation among the remaining sites.
ngammacat=4 Approximates the gamma distribution with four discrete rate categories.
prset statefreqpr=dirichlet(1,1,1,1) Assigns a flat Dirichlet prior to the four nucleotide frequencies. This is the default, but stating it records the assumption.
showmodel Prints the complete active model, parameter links, and priors. Save this output in the screen log.
mcmcp Changes MCMC settings without starting the run. mcmc accepts the same settings and starts sampling immediately.
nruns=2 Runs two independent analyses. Comparison between their samples supplies several convergence diagnostics.
nchains=4 Uses one cold chain and three heated chains in each run. Posterior samples come from the cold chain.
temp=0.1 Sets the heating coefficient for Metropolis coupling. Smaller values make adjacent chains more similar and increase swap acceptance; larger values make heated chains hotter.
ngen=2000000 Sets the target total to 2,000,000 MCMC generations. This example value must be increased when diagnostics remain inadequate.
samplefreq=1000 Writes a parameter and tree sample every 1,000 generations. The run stores approximately ngen / samplefreq samples before burn-in removal.
printfreq=1000 Prints progress every 1,000 generations. This affects the screen log, not the sampling interval.
mcmcdiagn=yes Writes move, swap, and topology-convergence diagnostics to <filename>.mcmc.
diagnfreq=5000 Calculates run-time diagnostics every 5,000 generations.
diagnstat=avgstddev Uses the average standard deviation of split frequencies (ASDSF) as the run-time topology diagnostic.
minpartfreq=0.10 Includes a split in ASDSF when its frequency is at least 0.10 in at least one run.
relburnin=yes Expresses burn-in as a fraction of saved samples rather than a fixed sample count.
burninfrac=0.25 Excludes the first 25% of saved samples from run-time diagnostics and the requested summaries. Check traces rather than treating 25% as universally adequate.
stoprule=no Runs to ngen instead of stopping automatically at an ASDSF threshold.
checkpoint=yes Writes chain state to a checkpoint file so an interrupted analysis can resume.
checkfreq=10000 Updates the checkpoint every 10,000 generations.
filename=alignment_gtrig Uses alignment_gtrig as the base name for output files.
sump Summarizes sampled scalar parameters, including credible intervals, effective sample sizes, and potential scale reduction factors.
sumt Summarizes sampled trees, split frequencies, branch parameters, consensus trees, and credible sets of trees.

The values of ngen, samplefreq, and burninfrac define the computational plan, not evidence that sampling is adequate. Extend the analysis when the retained samples fail the convergence and mixing checks below.

4 Likelihood models and priors

lset defines the likelihood model. prset defines priors on its parameters. Review the combined result with showmodel before sampling.

Common nucleotide settings include:

Setting Effect
lset nst=1 Uses one substitution-rate class: F81 with estimated state frequencies, or JC when statefreqpr=fixed(equal).
lset nst=2 Uses two substitution-rate classes: HKY with estimated state frequencies, or K80 when statefreqpr=fixed(equal).
lset nst=6 Uses six reversible substitution rates: GTR with estimated state frequencies, or SYM when statefreqpr=fixed(equal).
lset nst=mixed Uses reversible-jump MCMC to average across reversible nucleotide substitution models.
lset rates=equal Uses one rate for all sites.
lset rates=gamma Estimates gamma-distributed rate variation among sites.
lset rates=propinv Estimates a proportion of invariable sites without gamma-distributed variation.
lset rates=invgamma Combines an estimated invariable-site proportion with gamma-distributed variation.

Common prior settings include:

Setting Parameter controlled
prset statefreqpr=dirichlet(...) Stationary state frequencies.
prset revmatpr=dirichlet(...) Six reversible rates in a GTR model.
prset tratiopr=beta(...) Transition-to-transversion rate ratio in an nst=2 model.
prset shapepr=exponential(...) Shape of gamma-distributed among-site rate variation.
prset pinvarpr=uniform(...) Proportion of invariable sites.
prset brlenspr=... Branch-length prior.
prset topologypr=... Tree-topology prior and enforced topological constraints.

The distribution arguments use program-specific parameterizations. Inspect help prset and showmodel rather than transferring numeric prior arguments from another program.

For protein data, choose a fixed empirical rate matrix or average over the supported matrices:

prset aamodelpr=fixed(lg);
lset rates=gamma ngammacat=4;
prset aamodelpr=mixed;
lset rates=gamma ngammacat=4;

For a standard-character morphology matrix that deliberately excludes all constant characters, apply the corresponding ascertainment correction:

lset coding=variable rates=gamma;

Use coding=informative when the matrix contains only parsimony-informative characters. Use coding=all when the sampling process retained all character classes. The correction must match the way the matrix was assembled.

5 Partitioned analyses

Define character sets, assemble them into a partition, activate the partition, and specify which parameters are shared:

charset gene1_pos1 = 1-900\3;
charset gene1_pos2 = 2-900\3;
charset gene1_pos3 = 3-900\3;
charset gene2 = 901-1500;

partition genes = 4: gene1_pos1, gene1_pos2, gene1_pos3, gene2;
set partition=genes;

lset applyto=(all) nst=6 rates=gamma ngammacat=4;
unlink revmat=(all) statefreq=(all) shape=(all);
prset applyto=(all) ratepr=variable;
showmodel;

The expressions 1-900\3, 2-900\3, and 3-900\3 select the three codon positions. applyto=(all) applies a setting to every active partition; a list such as applyto=(1,3) targets selected partitions.

MrBayes initially links compatible parameters across partitions. unlink revmat=(all) statefreq=(all) shape=(all) gives each partition separate GTR rates, state frequencies, and gamma-shape parameters. Topology and branch lengths remain shared because the commands do not unlink them. ratepr=variable estimates relative rate multipliers across partitions. Use showmodel to verify every link and prior after changing the partition scheme.

6 Constraints and reported rooting

Define and enforce a positive monophyly constraint with:

constraint focal_clade = Taxon_D Taxon_E;
prset topologypr=constraints(focal_clade);

Defining a constraint does not enforce it; topologypr=constraints(...) activates the named constraints. Constraints are prior assumptions and must be recorded with the analysis.

For a non-clock analysis under a reversible model, set the outgroup used to orient displayed and summarized trees:

outgroup Taxon_A;

The outgroup command does not add statistical information about the root of an otherwise unrooted reversible-model analysis. Clock models infer rooted trees through their model and prior structure.

7 Convergence and mixing checks

Inspect the screen log, .mcmc, .pstat, .tstat, and .vstat files after every analysis. Use all relevant checks rather than a single threshold:

  • ASDSF compares split frequencies across independent runs and should approach zero. A value below 0.01 is a commonly used rough target, but agreement between runs does not prove that either run explored the complete posterior.
  • Potential scale reduction factors (PSRFs) compare within-run and between-run variation and should approach 1.0. The MrBayes manual gives 1.0–1.2 as a rough range, not a universal acceptance rule.
  • Effective sample size (ESS) estimates the amount of independent information in autocorrelated samples. Values below 100 indicate poor sampling in the MrBayes command reference. Larger values provide more stable posterior summaries.
  • Likelihood and parameter traces should be stationary after burn-in, without long trends or persistent separation among runs.
  • Posterior summaries and well-supported split frequencies should agree across independent runs.
  • Adjacent-chain swap acceptance rates appear in .mcmc and at the end of the run. The manual gives approximately 10%–70% as a useful range. Decrease temp when adjacent-chain swaps are too rare; increase it when they are uniformly too frequent.

If diagnostics are inadequate, extend the runs, improve Metropolis coupling, reconsider parameterization or partitioning, and repeat the summaries with an appropriate burn-in. Do not pool runs that converged to incompatible posterior regions.

Enable automatic stopping only when ASDSF is an appropriate stopping statistic and at least two runs are active:

mcmcp stoprule=yes stopval=0.01;

ngen remains the maximum generation. The stopping rule can terminate earlier when the run-time ASDSF falls below stopval; post-run diagnostics remain necessary.

8 Checkpoints and extending a run

MrBayes writes <filename>.ckp when checkpointing is enabled. To resume or extend an analysis, use the same data, model, number of runs, number of chains, sampling settings, and output filename. Set ngen to a total generation greater than the generation stored in the checkpoint, then use append=yes:

mcmcp ngen=4000000 filename=alignment_gtrig;
mcmc append=yes;

If the checkpoint contains generation 2,000,000, this command continues to generation 4,000,000; it does not add 4,000,000 generations. Preserve the checkpoint and existing .p and .t files together. After the extension, rerun sump and sumt with the selected burn-in.

9 Parallel execution

The serial executable uses one operating-system process. An MPI-enabled build distributes the nruns * nchains chains across MPI processes. For the standard two-run, four-chain analysis, there are eight chains and therefore no benefit from requesting more than eight MPI processes.

Run an MPI-enabled executable with resources granted by the scheduler:

mpirun -np 8 mb analysis.nex > alignment_gtrig.screen.log 2>&1

Choose a process count no greater than the total number of chains and, when practical, make the total chain count a multiple of the process count. Confirm with mb -v that the executable reports MPI support. Keep checkpointing enabled for scheduled jobs.

10 Output files

For filename=alignment_gtrig and nruns=2, the principal files are:

File Contents
alignment_gtrig.run1.p, .run2.p Tab-delimited scalar-parameter samples from each cold chain.
alignment_gtrig.run1.t, .run2.t Sampled trees and branch lengths from each cold chain in NEXUS tree format.
alignment_gtrig.mcmc Proposal acceptance, chain-swap, and run-time convergence diagnostics.
alignment_gtrig.ckp Checkpoint state used by mcmc append=yes.
alignment_gtrig.pstat Parameter posterior summaries from sump, including credible intervals, ESS, and PSRF.
alignment_gtrig.lstat Likelihood summaries from sump. Harmonic-mean estimates are not a substitute for stepping-stone sampling in model comparison.
alignment_gtrig.parts Key that maps split or clade identifiers to taxon bipartitions.
alignment_gtrig.tstat Split-frequency and topology-convergence summaries from sumt.
alignment_gtrig.vstat Branch and node parameter summaries from sumt.
alignment_gtrig.con.tre Consensus trees with posterior split or clade probabilities and branch summaries.
alignment_gtrig.trprobs Sampled topologies sorted by posterior probability, including cumulative credible sets.

Values on the consensus tree are posterior split or clade probabilities, not bootstrap proportions. Their interpretation is conditional on the data, likelihood model, priors, partition scheme, constraints, and adequacy of posterior sampling.

11 Operational checklist

  1. Prepare and inspect the aligned NEXUS matrix.
  2. Put analysis commands in a separate NEXUS file.
  3. Set seed and swapseed before executing the data file when exact starting-value reproducibility is required.
  4. Define the likelihood model, priors, partitions, and constraints.
  5. Run showmodel and preserve its output.
  6. Use at least two independent runs, adequate chain heating, checkpointing, and a unique output name.
  7. Run sump and sumt with a burn-in justified by the traces.
  8. Inspect ASDSF, PSRF, ESS, traces, split frequencies, proposal acceptance, and chain-swap acceptance.
  9. Extend the run with append=yes when posterior sampling is inadequate.
  10. Preserve the command file, input matrix, screen log, sample files, checkpoint, and summary files.
  11. Report the MrBayes version, likelihood model, priors, partition links, constraints, MCMC settings, burn-in, convergence diagnostics, and posterior summary procedure.
  12. Use the citations command to identify MrBayes and feature-specific methods that require citation.
