Julia help and documentation

Author

Jeet Sukumaran

Proficiencies
  • Using the Julia REPL help mode.
  • Accessing documentation with @doc.
  • Searching Julia docstrings.
  • Reading function signatures and method lists.
  • Inspecting the types involved in a function call.
  • Finding version-matched Julia and package documentation.
  • Preparing a reproducible request for help.

Julia provides documentation through the REPL. This documentation covers functions, types, macros, operators, and language keywords.

1 Help mode

Prefix a name with ? to display its documentation directly. For example, the documentation for iseven begins with:

julia> ?iseven
search: iseven isopen isnan isone seek setenv isletter

  iseven(x::Number) -> Bool

  Return true if x is an even integer (that is, an integer divisible by 2),
  and false otherwise.

The docstring also contains calls that can be run directly.

julia> iseven(9)
false

julia> iseven(10)
true

Typing ? by itself changes the prompt to help?> before the name is entered.

julia> ?
help?> iseven

Both forms query the same docstring. Press Backspace at an empty help?> prompt to leave help mode without running a query.

The prompt markers identify where to type each expression. Do not type the prompt markers themselves.

1.1 Querying Julia objects

Help mode accepts several kinds of Julia objects.

help?> Float64

help?> @time

help?> +

help?> begin

Use a qualified name to specify the module that defines an object.

help?> Base.Math.sin

Import a package before querying its documentation.

julia> import DataFrames

julia> ?
help?> DataFrames.DataFrame

1.2 The @doc macro

The @doc macro retrieves documentation from Julia mode. For example, the output from @doc range begins with:

julia> @doc range
  range(start, stop, length)
  range(start, stop; length, step)
  range(start; length, stop, step)
  range(; start, length, stop, step)

  Construct a specialized array with evenly spaced elements and optimized
  storage (an AbstractRange) from the arguments.

At the REPL, @doc range and ?range display the same documentation. @doc can also be used in Julia source code.

1.3 Searching docstrings

Enter a quoted string when the relevant Julia name is unknown.

help?> "matrix multiplication"

A regular expression can search for several related terms.

help?> r"eigen(value|vector)"

These searches use the docstrings loaded in the current session. Import the relevant package before searching its documentation.

2 Name completion

Press Tab after a partial name to list possible completions.

julia> prin<Tab>

Completion also works with qualified names.

julia> Base.Math.ac<Tab>

At the REPL, LaTeX-like sequences followed by Tab produce Unicode characters.

julia> \alpha<Tab>

This produces α.

3 Reading function documentation

Function documentation normally begins with one or more signatures. The range documentation shown above lists several ways to supply start, stop, length, and step.

In the following call, 1 and 10 are positional arguments and length is a keyword argument.

julia> range(1, 10; length=4)
1.0:3.0:10.0

julia> collect(range(1, 10; length=4))
4-element Vector{Float64}:
  1.0
  4.0
  7.0
 10.0

The semicolon separates positional arguments from keyword arguments. An entry such as step=1 in a signature gives the keyword’s default value. Square brackets in a documented signature indicate an optional argument; the brackets are not part of the Julia call.

3.1 Functions and methods

A Julia function can have several methods. Each method accepts a particular combination of positional argument types.

List all methods for a function with methods.

julia> methods(sqrt)

Restrict the result to a tuple of argument types when necessary.

julia> methods(sqrt, (Float64,))
# 1 method for generic function "sqrt" from Base:
 [1] sqrt(x::Union{Float32, Float64})
     @ math.jl:626

Use @which to show the method selected for a particular call.

julia> using InteractiveUtils: @which

julia> @which sqrt(16.0)
sqrt(x::Union{Float32, Float64})
     @ Base.Math math.jl:626

Method lists and source locations can change between Julia versions.

4 Inspecting arguments

Method selection depends on argument types. Inspect the values used in the failing or unfamiliar call.

julia> values = [1.0, 4.0, 9.0]

julia> typeof(values)
Vector{Float64}

julia> eltype(values)
Float64

julia> size(values)
(3,)

Common inspection functions include:

  • typeof(x) for the concrete type of x;
  • eltype(x) for the element type of a collection;
  • size(x) for its dimensions;
  • axes(x) for its valid indices; and
  • propertynames(x) for its public properties.

For example, sqrt("16") produces a MethodError because no sqrt method accepts a String.

julia> typeof("16")
String

julia> applicable(sqrt, "16")
false

If the string represents a number, parse it before calling sqrt.

julia> sqrt(parse(Float64, "16"))
4.0

5 Package documentation and versions

Help mode shows the docstring installed with the current package version. A package manual usually provides longer explanations and complete examples.

Check the active Julia version with:

julia> VERSION

Check the active project and package versions with:

julia> Base.active_project()

julia> import Pkg

julia> Pkg.status()

When consulting online documentation, select the version that matches the current environment.

6 Requesting help

A reproducible request for help includes:

  • the intended result;
  • the smallest complete example that produces the problem;
  • the complete error and relevant stack trace;
  • the observed and expected results;
  • the Julia and package versions; and
  • the documentation already checked.

Remove private paths, credentials, and confidential data before sharing code or diagnostic output. The Julia Discourse forum provides public categories for new-user and general-usage questions.

7 Exercises

7.1 Help-mode practice

Exercise 1

Use help mode to inspect range.

  1. Identify 2 documented call forms.
  2. Find the keywords that control the number of values and their spacing.
  3. Run one example of each form.

7.2 Method inspection

Exercise 2
Run sqrt(9) and sqrt(9.0). Use typeof on each argument and @which on each call. Record the selected method signatures.

7.3 Package documentation

Exercise 3
Import a package used elsewhere in this course. Inspect the package and one of its functions in help mode. Record the installed package version reported by Pkg.status() and locate the documentation for that version.
