The Newick tree format

Author

Jeet Sukumaran

1 The Newick tree format

1.1 A Newick tree expression

  • Commas used to separate nodes.
  • Parentheses used to group nodes.
  • Statement ends with a semicolon.

1.2 Internal nodes can be named by a label

Ancestors or other internal node information represented by text following closing parenthesis for that node.

((A,B)hello,(C,D)world)apple;

1.3 Branch lengths

Branch lengths of each edge represented by colon followed by value

((A:1,B:2):3,(C:4,D:5):6):7;

1.4 Branch lengths + internal labels

((A:1,B:2)hello:3,(C:4,D:5)world:6)said_the_hobbit:7;

2 The Newick data file format

We have discussed the Newick format for tree presentation previously, and, by now, you should all be familiar with expressing trees — rooted and unrooted — in this format. A Newick tree file is simply a collection of one or more Newic tree expressions, with each tree expression terminated by a semi-colon:

(A,(B,(C,D)));
(D,(A,(B,C)));
(A,(C,(D,B)));

The Newick format for trees is also used by the NEXUS format, discussed below.
