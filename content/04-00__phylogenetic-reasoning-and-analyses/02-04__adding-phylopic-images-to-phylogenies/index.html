Adding PhyloPic images to phylogenies

Author

Jeet Sukumaran

This tutorial develops 1 small analysis in the same order that we would work through it at the Julia REPL:

Newick string -> phylogeny object -> taxon resolution -> image URLs -> illustrated tree

PhyloPic provides reusable silhouettes of organisms. PhyloPicMakie will find 1 silhouette for each scientific name. PhyloMakie will attach the corresponding image URL directly to each tip.

1 Load the plotting packages

NoteRequired packages

GLMakie, PhyloMakie.jl, and PhyloPicMakie.jl need to be installed in the active environment. If this has not already been done, run:

using Pkg

Pkg.add("GLMakie")
Pkg.add("PhyloMakie")
Pkg.add(url = "https://github.com/JuliaPhylo/PhyloPicMakie.jl")

Load the packages with:

using GLMakie
using PhyloMakie
using PhyloPicMakie

2 Store and parse a phylogeny

This phylogeny contains 4 living bear species. The branch lengths after each colon will determine the horizontal positions of the nodes.

phylogeny_newick = "(Ailuropoda_melanoleuca:1.0,(Ursus_americanus:1.0,(Ursus_arctos:0.5,Ursus_maritimus:0.5):0.5):1.0);"

phylogeny = parsephylogeny(NewickFormat(), phylogeny_newick)
LineageNetwork(7 nodes, 6 edges, 4 tips, 0 hybrid nodes, rooted)

The underscores keep each scientific name together as 1 Newick label. We will replace them with spaces before asking PhyloPic to resolve the names.

3 Plot the tree before adding silhouettes

tree_result = plot(
    phylogeny;
    useedgelength = true,
    tipoffset = 0.2,
    xlim = (0.5, 5.0),
    ylim = (0.25, 4.75),
)

tree_result.figure

This is our first checkpoint. Confirm that the 4 tip labels are present and that Ursus arctos and Ursus maritimus are sister taxa.

4 Convert the tip labels to scientific names

tip_labels returns the tip labels stored in the phylogeny. Replace each underscore with a space so that PhyloPic receives ordinary scientific names.

tip_names = tip_labels(phylogeny)

tip_taxa = String[
    replace(tip_name, "_" => " ") for tip_name in tip_names
]

tip_taxa
4-element Vector{String}:
 "Ailuropoda melanoleuca"
 "Ursus americanus"
 "Ursus arctos"
 "Ursus maritimus"

Keep tip_names and tip_taxa in the same order. Each item in tip_names identifies a tip in the tree; the item at the same position in tip_taxa is the scientific name that we will ask PhyloPic to resolve.

5 Resolve the scientific names with PhyloPic

PhyloPicMakie’s PhyloPicDB namespace provides the data-access functions. Resolve all 4 names together so that they use the same PhyloPic data build.

const PhyloPicDB = PhyloPicMakie.PhyloPicDB

resolutions = PhyloPicDB.resolve_taxa(tip_taxa)
resolutions
4-element Vector{PhyloPicMakie.PhyloPicDB.TaxonResolution{PhyloPicMakie.PhyloPicDB.PhyloPicResolver}}:
 TaxonResolution("Ailuropoda melanoleuca", TAXON_RESOLVED, "Ailuropoda melanoleuca", uuid="1455312c-3f14-47e1-83c3-75178f59ca75")
 TaxonResolution("Ursus americanus", TAXON_RESOLVED, "Ursus americanus", uuid="4346dc12-dcf7-44e0-856f-276da1aa28cf")
 TaxonResolution("Ursus arctos", TAXON_RESOLVED, "Ursus arctos", uuid="b1cb4995-d8cf-41ef-b1c6-921fb7e1f90f")
 TaxonResolution("Ursus maritimus", TAXON_RESOLVED, "Ursus maritimus", uuid="79e06b0b-daef-47cf-88c1-a99b32125dde")

A resolution records whether a query selected 1 PhyloPic node, was ambiguous, or was not found. Check that every name resolved before plotting.

all(PhyloPicDB.isresolved, resolutions)
true

If the result is false, inspect the displayed resolutions before continuing. A misspelled or ambiguous name should be corrected explicitly. Do not silently attach an uncertain image to a tip.

6 Inspect the images and their licenses

Each PhyloPic image has its own reuse terms. The package’s license does not replace the license attached to an individual image. Display a small gallery that pairs each selected image with its taxon name and image license.

silhouette_gallery = phylopic_thumbnail_grid(
    resolutions;
    ncols = 2,
    image_layout = :flat,
    image_label = [:taxon_name, :license],
    label_lines = 2,
    title = "Resolved bear silhouettes",
    on_missing = :error,
)

silhouette_gallery

When publishing or redistributing a silhouette, retain its license, license_url, attribution, and contributor_href metadata and follow the terms attached to that image.

7 Get the image URLs

Each resolution may have a primary image. Retrieve those image records and check that every record provides a thumbnail URL.

image_records = PhyloPicDB.primary_image.(resolutions)

all(
    image_record -> !isnothing(image_record) && !ismissing(image_record.thumbnail_url),
    image_records,
)
true

Create a dictionary that maps each exact Newick tip label to its resolved thumbnail URL.

thumbnail_urls = Dict{String,String}()

for (tip_name, image_record) in zip(tip_names, image_records)
    thumbnail_urls[tip_name] = image_record.thumbnail_url
end

thumbnail_urls
Dict{String, String} with 4 entries:
  "Ursus_arctos"           => "https://images.phylopic.org/images/43e82541-0f4a…
  "Ailuropoda_melanoleuca" => "https://images.phylopic.org/images/4b1f7a58-8713…
  "Ursus_americanus"       => "https://images.phylopic.org/images/5a5dafa2-6388…
  "Ursus_maritimus"        => "https://images.phylopic.org/images/c11b4873-aa21…

Every dictionary key exactly matches 1 tip label in phylogeny_newick. That exact match tells PhyloMakie which image belongs to which tip.

8 Describe the image annotations

ImageAnnotation controls where and how large an image appears. Tips are 1 data unit apart vertically, so an image height below 1 leaves space between adjacent images.

image_height = 0.75

tip_images = Dict(
    tip_name => ImageAnnotation(
        image_url;
        height = image_height,
        position = :right,
        offset = (6, 0),
    ) for (tip_name, image_url) in thumbnail_urls
);

We now have 3 objects with separate jobs:

Object Role
phylogeny Stores the topology parsed from the Newick string.
thumbnail_urls Maps each exact tip label to its resolved image URL.
tip_images Adds placement and sizing instructions for each image.

9 Plot the illustrated tree

Pass the image dictionary directly to PhyloMakie’s nodeimages argument.

illustrated_result = plot(
    phylogeny;
    nodeimages = tip_images,
    useedgelength = true,
    tipoffset = 1.0,
    xlim = (0.5, 5.0),
    ylim = (0.25, 4.75),
)

illustrated_result.figure

Three arguments control the layout:

  • position = :right places each image to the right of its tip node.
  • offset = (6, 0) adds 6 pixels of horizontal space between the node and the image.
  • tipoffset = 1.0 moves the tip-label text far enough to clear the image.

PhyloMakie downloads, decodes, and caches each URL for this plot. We only need to provide the source URL and its image annotation.

10 REPL checkpoint

Change image_height from 0.75 to 0.55, rebuild tip_images, and rerun the illustrated-tree cell. The silhouettes should become smaller while the tree and labels stay unchanged.

Next change tipoffset from 1.0 to 1.2. Only the label text should move. The tree topology, taxon matches, and image sizes should stay unchanged.

NoteInternet connection

Taxon resolution and the first image download contact the PhyloPic service. Those steps therefore require an internet connection.
