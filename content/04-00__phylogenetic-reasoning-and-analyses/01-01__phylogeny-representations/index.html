Representing and reading phylogenies

Author

Jeet Sukumaran

Phylogenetic data move through 2 representations in a Julia workflow:

serialized text or file -> parser or reader -> phylogeny object

The Newick primer explains Newick punctuation, labels, and branch lengths. This tutorial focuses on selecting the Julia function that converts a data source into a phylogeny object. The visualization tutorial begins after that object exists.

1 Learning goals

By the end of this tutorial, you should be able to:

  • distinguish serialized phylogenetic content from a Julia phylogeny object;
  • construct 1 phylogeny from a literal Newick string;
  • choose singular or plural parsers for string content;
  • choose singular or plural readers for file paths; and
  • select NewickFormat() or NexusFormat() for the supplied content.

2 Load PhyloMakie

NoteRequired package

PhyloMakie.jl needs to be installed in the active environment. If this has not already been done, run:

using Pkg

Pkg.add("PhyloMakie")

Load the package with:

using PhyloMakie

3 Literal Newick content and phylogeny objects

A Julia string can store a serialized Newick expression:

bears_string = """
(
    Giant_Panda,
    (Andean_Bear,(American_Black_Bear,(Brown_Bear,Polar_Bear)))
);
"""
"(\n    Giant_Panda,\n    (Andean_Bear,(American_Black_Bear,(Brown_Bear,Polar_Bear)))\n);\n"

The variable bears_string contains text. It does not yet contain a phylogeny object.

parsephylogeny converts content containing exactly 1 phylogeny:

bears_phylogeny = parsephylogeny(NewickFormat(), bears_string)
LineageNetwork(9 nodes, 8 edges, 5 tips, 0 hybrid nodes, rooted)

The format object is explicit. NewickFormat() tells PhyloMakie how to interpret the supplied content.

4 The newick string macro

For 1 short literal expression, the newick string macro combines storage and parsing:

small_phylogeny = newick"(A,(B,C));"
LineageNetwork(5 nodes, 4 edges, 3 tips, 0 hybrid nodes, rooted)

Use the macro when the source appears literally in the program. Use parsephylogeny when the text comes from a variable, simulation, database response, or another computation.

5 Parse multiple phylogenies

A string can contain more than 1 phylogeny:

alternative_strings = """
((Giant_Panda,Andean_Bear),(Brown_Bear,Polar_Bear));
(Giant_Panda,(Andean_Bear,(Brown_Bear,Polar_Bear)));
"""
"((Giant_Panda,Andean_Bear),(Brown_Bear,Polar_Bear));\n(Giant_Panda,(Andean_Bear,(Brown_Bear,Polar_Bear)));\n"

parsephylogenies returns every phylogeny in a vector:

alternative_phylogenies = parsephylogenies(
    NewickFormat(),
    alternative_strings,
)
2-element Vector{LineageNetwork{Nothing, Nothing, Nothing}}:
 LineageNetwork(7 nodes, 6 edges, 4 tips, 0 hybrid nodes, rooted)
 LineageNetwork(7 nodes, 6 edges, 4 tips, 0 hybrid nodes, rooted)
length(alternative_phylogenies)
2

Use ordinary vector operations to select a result:

first_alternative = first(alternative_phylogenies)
second_alternative = alternative_phylogenies[2]
LineageNetwork(7 nodes, 6 edges, 4 tips, 0 hybrid nodes, rooted)

parsephylogenies returns a vector even when its source contains only 1 phylogeny. The singular parsephylogeny requires exactly 1 result and raises an ArgumentError when the source contains zero or multiple phylogenies.

6 Distinguish content from file paths

Strings can represent either literal content or a path. The function name determines which meaning applies.

Literal content

parsephylogeny(
    NewickFormat(),
    "(A,(B,C));",
)

File path

readphylogeny(
    NewickFormat(),
    joinpath(
        homedir(),
        "Downloads",
        "tree.tre",
    ),
)

The parse... functions treat a string as serialized content. The read... functions treat a string as a file path.

7 Create and read a Newick file

Copy the following expressions into a plain-text editor and save the file as example-phylogenies.tre:

((A:1,B:1)AB:2,(C:1,D:1)CD:2)root;
(A:1,(B:1,(C:1,D:1)CD:1)BCD:1)root;
((A:1,C:1)AC:2,(B:1,D:1)BD:2)root;

The file contains 3 phylogenies. Placing 1 expression on each line is a readable convention, but the terminating semicolons define their boundaries.

Store the path to the location where the file was saved:

newick_path = joinpath(
    homedir(),
    "Downloads",
    "example-phylogenies.tre",
)

Confirm that the path exists before reading it:

isfile(newick_path)

The file contains multiple phylogenies, so use the plural reader:

file_phylogenies = readphylogenies(
    NewickFormat(),
    newick_path,
)
length(file_phylogenies)

Use readphylogeny instead when the file must contain exactly 1 phylogeny.

8 Read phylogenetic data from a URL

A remote response becomes a local file before it is passed to a reader. The following URL requests tree Tr1453 from TreeBASE in NEXUS format:

Open or download TreeBASE tree Tr1453 as NEXUS

Julia’s standard-library Downloads module retrieves the response. The returned temporary-file path is then read with NexusFormat():

treebase_url = "https://treebase.org/treebase-web/phylows/tree/TB2:Tr1453?format=nexus"

treebase_phylogenies = readphylogenies(
    NexusFormat(),
    Downloads.download(treebase_url),
)
length(treebase_phylogenies)

The result should contain 1 phylogeny. The plural reader remains appropriate because a NEXUS trees block can contain more than 1.

9 Reader selection guide

Select a function by answering 2 questions: what kind of source was supplied, and how many phylogenies may it contain?

Source supplied to the function Exactly 1 phylogeny Zero or more phylogenies
String content or open IO stream parsephylogeny parsephylogenies
File path readphylogeny readphylogenies

Then select the format object:

NewickFormat()
NexusFormat()

10 Common failure modes

Symptom Likely cause Direct check
A filename is parsed as Newick content. A parse... function received a path. Replace it with the corresponding read... function.
A file cannot be found. The path does not identify the saved file. Run pwd() and isfile(path).
Only 1 of several phylogenies is accepted. A singular function was used. Use the corresponding plural function.
The parser rejects valid-looking text. The format object does not match the content. Check NewickFormat() versus NexusFormat().

11 Final synthesis

source + format + expected count
    -> parse or read
    -> phylogeny object
