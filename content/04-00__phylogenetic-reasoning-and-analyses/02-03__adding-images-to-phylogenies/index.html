Adding images to phylogenies

Author

Jeet Sukumaran

1 Setting up the environment

NoteRequired packages

GLMakie and PhyloMakie.jl need to be installed in the active environment. If this has not already been done, run:

using Pkg

Pkg.add("GLMakie")
Pkg.add("PhyloMakie")

Load the packages with:

using GLMakie
using PhyloMakie

2 Generating the phylogeny

phylogeny_newick = "(red,(orange,(yellow,(green,(blue,(indigo,violet))))));"
"(red,(orange,(yellow,(green,(blue,(indigo,violet))))));"
phylogeny = parsephylogeny(NewickFormat(), phylogeny_newick)
LineageNetwork(13 nodes, 12 edges, 7 tips, 0 hybrid nodes, rooted)

3 Plotting the phylogeny

plot_result = plot(
    phylogeny;
    useedgelength = false,
    tipoffset = 0.12,
)

5 Describing the image annotations

ImageAnnotation controls where and how large an image appears. Tips are 1 data unit apart vertically, so an image height below 1 leaves space between adjacent images.

image_height = 0.65

tip_images = Dict(
    label => ImageAnnotation(
        url;
        position = :right,
        height = image_height,
    ) for (label, url) in image_urls
);

We now have 3 objects with separate jobs:

Object Role
phylogeny Stores the topology parsed from the Newick string.
image_urls Maps each exact tip label to a supplied image URL.
tip_images Adds placement and sizing instructions for each image.

6 Adjusting the labels

First, keep the small tipoffset from the original tree plot. This lets us see why image placement and text placement need to be adjusted separately.

close_labels_result = plot(
    phylogeny;
    nodeimages = tip_images,
    useedgelength = false,
    tipoffset = 0.12,
    xlim = (0.5, 9.0),
    ylim = (0.25, 7.75),
)

close_labels_result.figure

Two arguments are doing different jobs:

  • position = :right places the left edge of each image at its tip node, so the image extends to the right of the tree.
  • tipoffset = 0.12 places each tip label only 0.12 x-axis data units to the right of its tip node.

The image and the label therefore occupy some of the same space. Changing position would move the image. To move only the text, change tipoffset.

Increase tipoffset while leaving tip_images unchanged. The tree topology, image size, and image placement all remain the same.

illustrated_result = plot(
    phylogeny;
    nodeimages = tip_images,
    useedgelength = false,
    tipoffset = 0.9,
    xlim = (0.5, 9.0),
    ylim = (0.25, 7.75),
)

illustrated_result.figure

The nodeimages argument adds the image dictionary to the live tree plot. The larger tipoffset moves the tip-label text past the images, and the explicit axis limits reserve space for both the images and the labels.
