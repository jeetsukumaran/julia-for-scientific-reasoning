Visualizing phylogenies

Author

Jeet Sukumaran

Proficiencies
  • create a phylogeny plot with plot;
  • distinguish topology-only and branch-length-scaled layouts;
  • display tip, node, and edge information;
  • draw a phylogeny into an existing Makie Axis with plot!; and
  • use the plotted node coordinates to add another Makie graphic.

1 Setting up the environment

NoteRequired packages

GLMakie and PhyloMakie.jl need to be installed in the active environment. If this has not already been done, run:

using Pkg

Pkg.add("GLMakie")
Pkg.add("PhyloMakie")

We load the PhyloMakie library into the active environment using:

using PhyloMakie

We also load the “Makie backend” rendering engine:

using GLMakie

2 Generating the phylogeny

The newick string macro converts a phylogeny represented as a Julia string (that is, a value of the Julia type, Base.String) in Newick format to a representation that PhyloMakie knows how to work with (a value of the type PhyloMakie.LineageNetwork):

phylogeny = newick"((A:1,B:4)AB:8,(C:2,D:6)CD:2)R:2;"
LineageNetwork(7 nodes, 6 edges, 4 tips, 0 hybrid nodes, rooted)
  • The construct "((A:1,B:4)AB:8,(C:2,D:6)CD:2)R:2;" is evaluated by Julia as a Base.String literal value.
  • The newick macro provided by PhyloMakie calls PhyloMakie.parsephylogeny to create and return a value of LineageNetwork type corresponding to the string value passed to it as its input argument.

3 Plotting the phylogeny

plot(phylogeny) creates a new figure (a value of type Makie.Figure), a new axis (Makie.Axis), and then plots the given phylogeny onto the new axis, with the result being a FigureAxisPlot value.

plot_result = plot(phylogeny)

This value has the properties figure, axis, and plot, holding the new Figure, Axis, and the phylogeny PhyloMakie.PhyloPlot values respectively:

propertynames(plot_result)
(:figure, :axis, :plot)
  • plot_result.figure is a Makie Figure, used to display or save as-is, or for additional composition with Makie.
  • plot_result.axis is a Makie Axis, used as a destination if we want to plot additional elements to the same drawing region and coordinate reference system as the phylogeny.
  • plot_result.plot is a PhyloMakie.PhyloPlot, the collectionh of points, lines, polygons, and other marks that make up the visualization of the phylogeny itself, used if we want to update the live plot with different values or aesthetics, or retrieve information about the phylogeny plot, such as the plotting coordinates of its nodes and iedges.

For example, to display the figure, just ask the REPL to evaluate its value:

plot_result.figure

while to save it to a file we would pass the figure to save:

save("phylogeny.png", plot_result.figure)

4 Setting plot attributes

Plot attributes control various aspects of the render.

For example the default useedgelength = false draws the topology without scaling branches by their stored lengths, so we have to explicitly overrride this with useedgelength = true to have branch extension in the plot proportional to the phylogeny edge weight values:

plot(phylogeny, useedgelength = true)

The full interface of the plotting function can be seen by inspecting the documentation of the plot type:

Some attributes can be updated live in interactive figures.

6 Compose using an existing Makie axis

When composing complex figures with Makie, it is useful to develop the figure in layers, which typically has us being responsible for the Figure and Axis creation. We use the mutating function variant of plot, plot!, passing it the Axis to mutate by adding the phylogeny plot as the first argument, and the phylogeny to plot as the second.

composed_figure = Figure(size = (900, 460))

composed_axis = Axis(
    composed_figure[1, 1];
    title = "A composed phylogeny figure",
)

composed_tree_plot = plot!(
    composed_axis,
    phylogeny;
    useedgelength = true,
    tipoffset = 0.2,
    xlim = (-1, 13),
)

The figure and axis remain available for additional panels, labels, legends, and annotations.
