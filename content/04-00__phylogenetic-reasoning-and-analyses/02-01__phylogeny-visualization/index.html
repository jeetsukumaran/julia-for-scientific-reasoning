Visualizing phylogenies

Author

Jeet Sukumaran

Proficiencies
  • create a phylogeny plot with plot;
  • distinguish topology-only and edge-length-scaled layouts;
  • display leaf, node, and edge information;
  • draw a phylogeny into an existing Makie Axis with plot!; and
  • use the plotted node coordinates to add another Makie graphic.
Related
  • Creating Makie figures
  • The phylogeny representations tutorial explains how to parse strings and read files.
  • The Newick primer describes the format’s punctuation and grammar.

1 Setting up the environment

NoteRequired packages

GLMakie and PhyloMakie.jl need to be installed in the active environment. If this has not already been done, run:

using Pkg

Pkg.add("GLMakie")
Pkg.add("PhyloMakie")

We load the PhyloMakie library into the active environment using:

using PhyloMakie

We also load the “Makie backend” rendering engine:

using GLMakie

2 Generating the phylogeny

The newick string macro converts a phylogeny represented as a Julia string (that is, a value of the Julia type, Base.String) in Newick format to a representation that PhyloMakie knows how to work with (a value of the type PhyloMakie.LineageNetwork):

phylogeny = newick"((A:1,B:4)AB:8,(C:2,D:6)CD:2)R:2;"
LineageNetwork(7 nodes, 6 edges, 4 leaves, 0 hybrid nodes, rooted)
  • The construct "((A:1,B:4)AB:8,(C:2,D:6)CD:2)R:2;" is evaluated by Julia as a Base.String literal value.
  • The newick macro provided by PhyloMakie calls PhyloMakie.parsephylogeny to create and return a value of LineageNetwork type corresponding to the string value passed to it as its input argument.

3 Plotting the phylogeny

plot(phylogeny) creates a new figure (a value of type Makie.Figure), a new axis (Makie.Axis), and then plots the given phylogeny onto the new axis. It returns these objects in a FigureAxisPlot value.

plot_result = plot(phylogeny)

This value has the properties figure, axis, and plot, which hold the new Figure, Axis, and PhyloMakie.PhylogenyPlot values, respectively:

propertynames(plot_result)
(:figure, :axis, :plot)
  • plot_result.figure is a Makie Figure, used to display or save as-is, or for additional composition with Makie.
  • plot_result.axis is a Makie Axis, used as a destination if we want to plot additional elements to the same drawing region and coordinate reference system as the phylogeny.
  • plot_result.plot is a PhyloMakie.PhylogenyPlot, which holds the points, lines, text, and other marks that visualize the phylogeny. We use this value to update plot attributes or retrieve information such as node coordinates.

For example, to display the figure, just ask the REPL to evaluate its value:

plot_result.figure

while to save it to a file we would pass the figure to save:

save("phylogeny.png", plot_result.figure)

4 Setting plot attributes

Plot attributes control various aspects of the rendered phylogeny.

For example, the default useedgelength = false draws the topology without scaling edges by their stored lengths. We set useedgelength = true to make each edge extension proportional to its phylogeny edge length:

plot(phylogeny, useedgelength = true)

The full interface of the plotting function can be seen by inspecting the documentation of the plotting function provided by PhyloMakie:

5 Reactive plots: updating attributes of a live plot

The plot_result.plot value is a handle to the existing phylogeny plot. The update! function changes one or more attributes of that plot. A call has this form:

update!(
    plot_result.plot;
    edgecolor = "steelblue",
    leaffontsize = 20,
)

The first argument identifies the plot to change. Each keyword argument names an attribute and supplies its new value. The ! at the end of update! indicates that the function changes the existing plot.

5.1 Switching between topology and edge-length layouts

We first set useedgelength = false. PhyloMakie calculates edge extensions from the topology, so the horizontal spacing represents topological depth rather than the stored edge lengths.

update!(plot_result.plot; useedgelength = false)

We then change the same attribute to true. The existing plot recalculates its horizontal coordinates from the edge lengths stored in phylogeny.

update!(plot_result.plot; useedgelength = true)

5.2 Hiding and showing edge lengths

The showedgelength attribute controls the numeric labels drawn beside the edges. We begin with the labels hidden.

update!(plot_result.plot; showedgelength = false)

We show the stored edge lengths by changing the attribute to true.

update!(plot_result.plot; showedgelength = true)

5.3 Updating several attributes together

A single call to update! can change several related attributes. Here we hide the edge lengths, show the internal-node names and edge numbers, recolor the edges and edge numbers, and increase the label font size:

update!(
    plot_result.plot;
    showedgelength = false,
    shownodelabel = true,
    showedgenumber = true,
    edgecolor = "steelblue4",
    edgenumbercolor = "darkorange",
    leaffontsize = 24,
)

5.5 Updating the axis

The axis is separate from the PhylogenyPlot, so its attributes are changed through plot_result.axis. The following assignments add a title and x-axis ticks, show the vertical grid, hide the horizontal grid, and remove the top and right spines:

plot_result.axis.title = "Edge-length-scaled phylogeny"
plot_result.axis.xticks = 0:2:12
plot_result.axis.xgridvisible = true
plot_result.axis.ygridvisible = false
plot_result.axis.topspinevisible = false
plot_result.axis.rightspinevisible = false

6 Compose using an existing Makie axis

When composing complex figures with Makie, we can build a figure in layers by creating the Figure and Axis ourselves. We pass the axis as the first argument to plot! and the phylogeny as the second. The plot! function adds the phylogeny to the existing axis and returns the new PhylogenyPlot directly.

composed_figure = Figure(size = (900, 460))

composed_axis = Axis(
    composed_figure[1, 1];
    title = "A composed phylogeny figure",
)

composed_tree_plot = plot!(
    composed_axis,
    phylogeny;
    useedgelength = true,
    leafoffset = 0.2,
    xlim = (-1, 13),
)

The figure and axis remain available for additional panels, labels, legends, and annotations.
