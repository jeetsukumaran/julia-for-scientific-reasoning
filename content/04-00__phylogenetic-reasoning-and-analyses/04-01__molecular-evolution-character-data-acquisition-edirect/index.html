Acquiring molecular characters with EDirect from Julia

Author

Jeet Sukumaran

NCBI Entrez Direct (EDirect) searches and retrieves records from NCBI’s Entrez databases. Julia can run EDirect programs from the REPL and keep the returned records as text or save them to files.

1 Preparation

1.1 Installing EDirect

Run the official EDirect installer from a system shell:

sh -c "$(curl -fsSL https://ftp.ncbi.nlm.nih.gov/entrez/entrezdirect/install-edirect.sh)"

Accept the installer’s offer to add EDirect to PATH. Open a new terminal, then confirm that the required programs are available:

command -v esearch efetch epost xtract
/home/student/edirect/esearch
/home/student/edirect/efetch
/home/student/edirect/epost
/home/student/edirect/xtract
esearch -version
26.2

The paths contain the local user name. The installed version may be newer than the version shown here.

NoteInstallation details

EDirect runs on Unix and macOS. On Windows, run EDirect and Julia in a Unix-compatible environment such as Windows Subsystem for Linux (WSL).

The EDirect manual contains the current installer command. The release notes record changes to EDirect programs and output.

1.2 Starting a working directory

Create a project directory with a directory for raw downloads, then make the project directory current:

mkdir -p /home/student/projects/learning/scientific-julia/bear-edirect-project/data/raw
cd /home/student/projects/learning/scientific-julia/bear-edirect-project

2 Basic workflow

2.1 Basic workflow for a single record

The accession NC_009492.1 identifies a complete mitochondrial genome for the giant panda, Ailuropoda melanoleuca. Retrieve the record in FASTA format and save it in the project’s raw-data directory.

Shell commands

The direct shell commands for this are:

efetch -db nuccore -id NC_009492.1 -format fasta \
    > data/raw/NC_009492.1.shell.fasta

-db nuccore selects the NCBI Nucleotide database. -id NC_009492.1 identifies the record, and -format fasta requests FASTA output. The backslash continues the command on the next line. The shell’s > operator writes the standard output to the path on its right.

Inspect the first line of the saved record:

head -n 1 data/raw/NC_009492.1.shell.fasta
>NC_009492.1 Ailuropoda melanoleuca mitochondrion, complete genome

The Julia REPL can construct and run the same EDirect command. Start Julia from the project directory:

julia --project=.

Represent the raw-data directory and accession as Julia strings:

raw_dir = joinpath("data", "raw")
"data/raw"
accession = "NC_009492.1"
"NC_009492.1"

Interpolate the accession into the command and capture the returned text:

fasta_record = read(
    `efetch -db nuccore -id $accession -format fasta`,
    String,
)

The first argument to read is the EDirect command. The second argument, String, specifies that read must return the command’s standard output as a Julia string.

Inspect the FASTA header:

first(split(fasta_record, '\n'))
">NC_009492.1 Ailuropoda melanoleuca mitochondrion, complete genome"

Save the returned text:

fasta_path = joinpath(raw_dir, "NC_009492.1.julia.fasta")
"data/raw/NC_009492.1.julia.fasta"
write(fasta_path, fasta_record)
1222
isfile(fasta_path)
true

write receives the destination path first and the captured FASTA text second.

NoteExternal commands in Julia

Backticks construct a Julia Cmd value. They do not run the command by themselves. A Cmd value is a template for a command that will be executed in the shell by functions such as run, read, or pipeline when passed as the first argument, with $-prefixed constructs replaced by the Julia value.

Here, $accession will be replaced with its string value when the argument is added to the efetch command in the shell.

read(command, String) runs the command and captures its standard output as a Julia string. See Julia’s external-program documentation for the complete command interface.

TipAccession versions

The .1 suffix identifies the exact version of the record. Retaining the version suffix makes the selected database record explicit.

2.2 Basic workflow for multiple records

EDirect accepts multiple accession versions as one comma-separated -id argument. The following three accessions identify complete mitochondrial genomes for a giant panda, a brown bear, and a polar bear. Retrieve the records as one FASTA stream and save it in the project’s raw-data directory.

Shell commands

The direct shell commands for this are:

efetch \
    -db nuccore \
    -id NC_009492.1,NC_003427.1,NC_003428.1 \
    -format fasta \
    > data/raw/three-bear-mitogenomes.shell.fasta

A backslash at the end of a shell line continues the command on the next line. The output file contains the three FASTA records in one stream.

Count the FASTA headers to confirm the number of records:

grep -c '^>' data/raw/three-bear-mitogenomes.shell.fasta

example_accessions = [

2.3 Searching when the accession is unknown

An Entrez query can combine an organism, a gene, a genomic location, and a sequence-length range. This query finds mitochondrial CYTB records from Ailuropoda melanoleuca with lengths from 1,000 through 1,200 nucleotides:

panda_cytb_query = "txid9646[ORGN:noexp] AND CYTB[GENE] AND mitochondrion[FILT] AND 1000:1200[SLEN]"
"txid9646[ORGN:noexp] AND CYTB[GENE] AND mitochondrion[FILT] AND 1000:1200[SLEN]"

esearch finds the matching records. efetch returns their accession numbers:

candidate_accessions = read(
    pipeline(
        `esearch -db nuccore -query $panda_cytb_query`,
        `efetch -format acc`,
    ),
    String,
)
print(candidate_accessions)
AY390359.1
AY390360.1
KP306772.1
KP306773.1

NCBI database contents change. A later search may return a different set or order.

NoteQuery terms

txid9646[ORGN:noexp] restricts the organism to NCBI Taxonomy ID 9646 without expanding the search to descendant taxa.

CYTB[GENE] searches the gene field. mitochondrion[FILT] restricts the location, and 1000:1200[SLEN] restricts sequence length.

The EDirect search documentation lists the available fields and filters.

NoteCommand pipelines

pipeline(search_command, fetch_command) connects the output of esearch to the input of efetch. read(..., String) captures the output of the final program.

The structured message between EDirect programs includes the active database and the matching record set. The later command therefore does not repeat the database name or record identifiers.

Inspect the accession, length, and title of each candidate before selecting a record:

candidate_table = read(
    pipeline(
        `esearch -db nuccore -query $panda_cytb_query`,
        `efetch -format docsum`,
        `xtract -pattern DocumentSummary -element AccessionVersion Slen Title`,
    ),
    String,
)
print(candidate_table)

WarningNCBI request limits

Keep repeated searches sequential. Do not wrap the request loop in parallel execution.

4.3 Posting an accession collection

For larger identifier collections, epost places the identifiers on the Entrez History server. Construct the newline-separated input:

accession_input = join(accessions, '\n') * "\n"
"NC_009492.1\nNC_009968.1\nNC_009970.1\nNC_009969.1\nNC_003426.1\nNC_003427.1\nNC_003428.1\nNC_009971.1\n"

Supply the string to epost through standard input and capture the returned history message:

posted_accessions = read(
    pipeline(
        `epost -db nuccore`
        stdin = IOBuffer(accession_input),
    ),

Change the taxonomic scope

  1. Select another NCBI Taxonomy ID.
  2. Retrieve its specified, non-extinct species.
  3. Save the exact query and returned Taxonomy table.

Compare marker availability

  1. Add another mitochondrial or nuclear marker to markers.
