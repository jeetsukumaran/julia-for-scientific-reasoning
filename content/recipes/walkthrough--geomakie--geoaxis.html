Geospatial data visualization with GeoMakie.GeoAxis

Author

Jeet Sukumaran

0.0.1 Geospatial data visualization: minimal working example

using GeoMakie, CairoMakie
1fig = Figure()
2ax = GeoAxis(fig[1, 1])
3lines!(ax, GeoMakie.coastlines())
fig
1
Create a Figure object: container for the plots
2
Create a GeoAxis object in cell (1, 1) of the Figure container: a specialized plotting axis that maps points from various geographical coordinate reference into Cartesian plotting planar coordinate systems; fig[1, 1] assigns it to the cell (1, 1), which is the only cell in a single plot figure.
3
Use the lines! function to plot coastline data on the GeoAxis plotting axis.
